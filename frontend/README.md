# Orderly frontend

React/Vite frontend for the Orderly personal organization site.

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Then open the URL printed by Vite, usually:

```text
http://127.0.0.1:5173
```

The app still uses mock authentication and local browser storage. Starter spaces are loaded from `data/projects.xml`; user-created spaces are stored in `localStorage`.
